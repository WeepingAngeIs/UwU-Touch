Nova Macro Hub - reference-inspired mascot update

Run the app:
1. Extract the entire ZIP to a new folder.
2. Run "1 - Install (first time).bat" if this folder has not been installed.
3. Run "2 - Start Nova Macro Hub.bat".
This is a runnable Python project, not a prebuilt EXE. The original EXE build script is included and already bundles the assets folder.

The System Tray panel now uses assets/nova-heart-mascot.png: a transparent pink-haired, cat-eared chibi character holding a heart, inspired by the supplied reference. It scales proportionally and sits beside the existing controls and caption. Controls and macro/Discord functionality are preserved.

If you previously chose a custom mascot, it is still respected. To show the new default, use Settings > Appearance > Mascot picture > Use cat.

Validation: 53 existing tests passed. Off-screen layout checks passed at 1100x700, 1560x1000 and 1920x1080. Transparency, bundled image loading, missing custom-image fallback, and no overlap with tray checkboxes verified. EXE packaging was not run.
